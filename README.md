# 分纤箱布点估算工具

本地单机网页工具：上传村地图截图，标注路网、户点、光缆进村点（可选已有分纤箱），自动计算分纤箱布点，输出标注图和数量清单（分纤箱数量、杆子根数、主干光缆长度），用于快速估算工程量和判断是否需要补箱。

## 使用

双击 `index.html` 用浏览器打开即可（Chrome / Edge），不需要联网、不需要安装。

1. **上传地图**：加载村地图截图（建议带比例尺）。
2. **比例校准**：选"比例校准"工具，沿地图自带比例尺（或任意已知距离）点两个点，输入实际米数。这决定后续所有长度换算。
3. **画路网**：选"路网"工具，沿村子的路点击，双击或点"完成当前路"结束一段。
4. **点户点**：每户点一个点（一个点 = 一户）。
5. **标进村点**：点击光缆进村的位置。
6. （可选）**已有箱**：有箱补点模式下，把已有分纤箱点在图上。
7. 设置参数（覆盖距离默认 100 米、每箱 16 户、杆距 50 米），选模式（无箱新建 / 有箱补点），点**计算布点**。
8. 导出：标注图 PNG、清单 CSV、示意 CAD（DXF）。

## 说明

- 户到分纤箱的距离按**直线距离**计算（皮线近似直线）；光缆长度按**沿路网最短路径**计算（从进村点到各箱）。
- 光缆长度为**主干光缆**，不含到户皮线（客户确认皮线不算）。
- 有箱补点模式：已有箱覆盖距离内的住户视为已覆盖（不占 16 户容量，客户确认已有箱有冗余），仅对覆盖不到的住户计算新增箱。
- 杆子根数 = 向上取整(主干光缆长度 ÷ 杆距)，默认 50 米一根。
- 补箱模式同时输出"主干光缆总长"与"新增光缆长度"（含新箱路由长度 − 仅已有箱路由长度）。
- 距离、容量、杆距均为可调参数；"差不多就行"通过调参数实现。

## 输出格式

- **PNG**：全分辨率标注图（箱位、编号、覆盖圈、光缆路由、杆位、户点归属）。
- **CSV**：清单（箱数、杆数、光缆米数、每箱明细），Excel 可直接打开。
- **DXF**：示意 CAD，分图层（ROAD/CABLE/BOX/EXIST/POLE/HOUSE/ENTRANCE），AutoCAD 可直接打开。坐标系为图片像素原点换算成米（Y 轴与地图图像方向一致），为方案示意用途，**不含坐标精度，不能用于现场放线**。
- **工程 JSON**：保存/打开整个工程（含地图、标注、参数、结果），浏览器也会自动暂存上次工程。

## 目录

- `index.html` / `style.css` / `app.js`：界面与交互
- `core.js`：核心算法（路网建图、选址、路由），无 DOM 依赖
- `tests/core.test.js`：算法自测（Node：`node tests/core.test.js`）

## 范围边界

不含自动识别房屋/道路、不含坐标精度与 GIS 坐标系、不含服务器部署与多人在线使用、不含施工图级 CAD。
